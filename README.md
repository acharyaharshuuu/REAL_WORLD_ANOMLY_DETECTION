# REAL-WORLD PUBLIC NUISANCE AND ANOMALOUS ACTIVITY DETECTION USING COMPUTER VISION

A modular research/engineering implementation around a CNN+LSTM video-activity pipeline. The existing research notebooks are intentionally treated as reference material and are not regenerated by this scaffold.

## Architecture

Video → frame sampling → 16-frame clip → pretrained ResNet18 → 16×512 spatial features → LSTM → activity class + confidence → temporal event generation → potential incident → output/dashboard.

ResNet18 provides spatial understanding; the LSTM models temporal relationships across the sampled sequence.

## Dataset

The supplied implementation expects a simple class-directory layout:

```text
data/raw/UCF_Crime/<ClassName>/*.mp4
```

Class names are discovered from directory names and saved with the trained model. If the existing notebooks use another UCF-Crime organization or a specific split protocol, align `train.py` with that notebook before training; no undocumented class list is assumed here.

## Installation

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Training

```bash
python train.py --dataset data/raw/UCF_Crime --epochs 5 --batch-size 4
```

The training pipeline samples frames incrementally and does not extract the entire dataset as JPG files. The saved artifacts are:

- `models/trained/cnn_lstm_model.pth`
- `models/trained/class_names.json`
- `models/trained/model_config.json`

## Inference

```bash
python app.py test_videos/input/sample.mp4
```

The application reports potential incidents, model confidence, timestamps and duration. Predictions are alerts for human review—not confirmed crimes or identification of a person as a criminal.

## Baseline vs final model

The research project retains the conceptual baseline of averaging 16 ResNet18 features and classifying the resulting 512-D vector, versus the final 16×512 sequence fed to an LSTM. Baseline experiment implementation should follow the existing notebook before being promoted into production code.

## Limitations

- Exact notebook-specific dataset split, sampling rate and LSTM hyperparameters have not been inferred where the notebooks were unavailable in this workspace.
- UCF-Crime labels represent dataset categories; they should not be interpreted as legal determinations.
- Event generation is heuristic post-processing and requires human review.

## Responsible AI / Human Review

Use terms such as **Potential Incident**, **Detected Anomalous Activity**, **Model Confidence**, and **Requires Human Review**. Do not present a model prediction as a confirmed crime, criminal identification, or guilt determination.
